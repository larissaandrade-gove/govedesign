# Logos locais (opcional)

No Lovable os logos vêm de `/__l5e/assets-v1/...` (ver `src/assets/*.asset.json`).
Fora do Lovable esse caminho não existe; coloque aqui uma cópia dos arquivos
com o nome original e o app passa a usá-los primeiro:

| Arquivo | Versão |
| --- | --- |
| `Asset_6.png` | Wordmark roxo + sorriso dourado (fundo claro) |
| `Asset_7.png` | Wordmark roxo monocromático (fundo claro) |
| `Asset_2.png` | Wordmark branco + sorriso dourado (fundo escuro) |
| `Asset_8.png` | Wordmark branco monocromático (fundo escuro) |

Sem os arquivos, o app tenta o endereço do Lovable e, se falhar, desenha o
texto "GOVE" no lugar do wordmark (comportamento original).
